# Projeto GJM - Virtual EPI Training Experience

## 📌 Sobre o Projeto

O Virtual EPI Training Experience é uma plataforma de treinamento imersivo desenvolvida para transformar a forma como colaboradores aprendem sobre Equipamentos de Proteção Individual (EPIs).

Através de um ambiente virtual interativo, os usuários podem explorar diferentes salas temáticas, aproximar-se dos equipamentos e acessar conteúdos educativos de maneira intuitiva e envolvente.

O projeto foi desenvolvido durante um hackathon com o objetivo de demonstrar como tecnologias imersivas podem aumentar o engajamento, melhorar a retenção de conhecimento e contribuir para treinamentos mais eficientes e padronizados.

---

## 🎯 Problema

Treinamentos convencionais frequentemente apresentam desafios como:

* Baixo engajamento dos participantes;
* Dificuldade de retenção do conteúdo;
* Necessidade de deslocamento para treinamentos presenciais;
* Falta de padronização entre diferentes unidades;
* Custos elevados de capacitação.

---

## 💡 Solução

Nossa solução consiste em um ambiente virtual 3D onde os colaboradores podem:

* Navegar livremente por salas temáticas;
* Interagir com diferentes EPIs;
* Receber explicações através de áudio e texto;
* Aprender de forma prática e visual;
* Realizar treinamentos em qualquer local.

A experiência torna o aprendizado mais acessível, moderno e envolvente.

---

## 🕹️ Experiência do Usuário

1. O usuário acessa o ambiente virtual.
2. Escolhe uma área de treinamento.
3. Caminha pelo cenário utilizando os controles do sistema.
4. Aproxima-se de um EPI disponível para treinamento.
5. Interage com o equipamento.
6. Recebe informações através de áudio explicativo e conteúdo visual.
7. Continua explorando os demais itens disponíveis.

---

## 🦺 EPIs Disponíveis

Exemplos de equipamentos presentes no ambiente:

* Capacete de segurança
* Óculos de proteção
* Luvas de proteção
* Protetor auricular
* Máscara respiratória
* Extintor de incêndio
* Hidrante

*(Os itens podem variar conforme a evolução do projeto.)*

## 🔧 Instalação

### Clonar o repositório

```bash
git clone https://github.com/jorgejr100/Projeto_GJM_Hackathon
```

### Abrir no Unity

1. Abra o Unity Hub.
2. Clique em "Open Project".
3. Selecione a pasta do projeto.
4. Aguarde a importação dos assets.

### Executar

1. Abra a cena principal.
2. Clique em Play dentro do Unity.
